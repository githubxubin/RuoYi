# 老项目结构识别

老项目首次接入、项目地图缺失或明显过期时，在“五环节主流程”的第 1 环节执行。它是需求与任务计划中的条件活动，不是新的主流程阶段。

## 触发条件

满足任一条件时触发：

- 仓库已有业务代码，但没有可信的 `docs/ai/project-map.md`；
- 当前任务涉及项目地图未覆盖的模块；
- 构建文件、路由、模块、公共资产、接口或数据访问层明显变化；
- 已记录的启动命令失效，项目无法达到页面或接口可访问状态；
- 用户明确要求重新识别项目结构。

项目地图存在且相关证据仍有效时，只抽样核对本次模块，不做全量扫描。

## 智能体分工

甲乙是可选执行方式，不是默认自动动作。这里的“智能体”包括 Orca Worker、模型内置子 Agent、后台 Agent、`Task`/`Explore` Agent和其他委派机制。主控首次委派前必须先创建 `docs/ai/runs/<任务编号>/00-run-plan.md`，说明识别范围，然后等待用户选择：主控创建并调度、用户手动创建，或不创建 Agent 由主控独立识别。未获得选择不得委派。

```text
主控智能体：确定范围、汇总证据、写项目地图、确认疑点
├── 工作智能体甲：代码结构与复用资产（只读）
└── 工作智能体乙：运行、接口、数据与测试（只读）
```

甲乙在当前工作树并行读取，不修改业务代码，不需要额外写入工作树。甲乙只返回结构化发现，由主控唯一写入项目地图，避免报告冲突。

### 甲：代码结构与复用资产

识别：

- 仓库结构、模块边界和依赖方向；
- 前端框架、入口、路由、状态管理、组件、样式和构建方式；
- 后端框架、启动入口、路由/控制器、服务、数据访问和中间件；
- 公共组件、工具、基类、响应封装、错误模型和权限组件；
- 命名、目录、测试放置和代码风格约定；
- 本次任务可以复用的现有资产。

### 乙：运行、接口、数据与测试

识别：

- 安装、构建、启动、静态检查和测试命令；
- 环境变量名称和配置来源，不读取或输出明文凭据；
- 前端调用到接口、后端处理函数和数据实体的映射；
- 鉴权、权限、跨域、代理和外部服务依赖；
- 数据库类型、迁移机制、核心实体/表和事务边界；
- 单元、集成、端到端测试和持续集成入口；
- 项目是否能在本地达到页面或接口可访问状态。

## 识别方法

### 1. 建立索引

- 列出代码、配置、构建和测试文件的路径、类型和大小。
- 排除 `.git`、依赖目录、构建产物、缓存、覆盖率和生成文件。
- 根据构建文件、入口、路由和导入关系找出核心资产候选。

### 2. 精读核心证据

只精读会影响开发决策的文件：构建配置、应用入口、路由、鉴权、中间件、请求封装、统一响应、数据访问、迁移、公共组件、测试基类和持续集成配置。

不得凭目录名称推断架构。重要结论必须附真实文件路径；无法确认的内容进入疑点清单。

### 3. 运行验证

| 层级 | 验证内容 | 通过标准 |
|---|---|---|
| R1 配置与依赖 | 工具链、依赖和必要配置名称 | 无致命缺失，凭据由人配置 |
| R2 构建/启动 | 执行项目真实命令 | 构建成功或进程稳定 |
| R3 端口/进程 | 预期端口和进程 | 不拒绝连接，进程未立即退出 |
| R4 页面/接口 | 页面或健康接口 | 返回有效页面、JSON 或合理鉴权响应 |
| R5 登录链路 | 真实认证和权限 | 尽力验证，阻塞时明确记录 |

进入开发前至少达到 R4。若受账号、网络或外部权限阻塞，由用户决定是否接受 mock、局部启动或其他降级方式。不得为通过验证修改业务代码。

## 项目地图

主控使用 `assets/legacy-project-map.md` 生成：

```text
docs/ai/project-map.md
```

项目地图包含八部分：

1. 系统概览与技术栈；
2. 模块边界与依赖；
3. 前端结构；
4. 后端结构；
5. 接口、鉴权和数据映射；
6. 公共资产和强制复用项；
7. 构建、启动、测试与运行验证；
8. 项目约定、关键疑点和证据索引。

默认使用一份项目地图，避免维护八份容易漂移的报告。超大单体或多仓库系统可以按模块拆分，但必须保留总索引。

## 放行条件

- 本次模块的边界、入口和依赖已经确认；
- 构建、启动和测试命令来自真实配置或实际执行；
- 接口、鉴权、数据和公共资产都有路径证据；
- 至少达到 R4，或者用户明确接受记录在案的降级方式；
- 会影响实现的疑点已经确认；
- 主控能据此划分甲乙互不重叠的文件所有权。

## 防止项目地图腐化

- 开发结束后只回写本次实际改变的模块、接口、公共资产和命令。
- 每次任务开始只抽样核对相关证据，不重复全量扫描。
- 证据文件删除、移动或与结论冲突时，将对应部分标记为过期并局部重扫。
